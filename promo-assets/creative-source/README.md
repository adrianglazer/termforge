# Termforge Apple creative assets

Upload `../promo-app-store/header/header.png` to the Header slot (3840×1646).
Upload `../promo-app-store/search-results/search-results.png` to the Search Results
slot (1920×1280). Both are opaque RGB PNGs. They remain outside the website.

The background was made with the built-in ImageGen tool, using `assets/icon.png`
as a palette/material reference. The app icon and two redacted, actual iPhone
screenshots were composited with FFmpeg. App UI was not generated or redrawn.
The screenshot status bars were cropped; usernames are `admin`, and host details
remain hidden. Text is rendered directly from DejaVu fonts.

Regenerate compositions with `python3 promo-assets/prepare-creative.py` from the
repository root. Retain this background and the two redacted screenshot sources.

## Background prompt

Create a premium, very restrained landscape background for Termforge, an iPhone
SSH terminal app. Use the provided app icon ONLY as a reference for material and
palette, not as an edit target. Background artwork only, no text, no logo, no
terminal symbol, no devices, no screens, no UI, no photographic objects. Wide
composition roughly 21:9. Near-black graphite and fine forged metal grain. Soft
amber-orange reflected glow along the lower edge and right outer edge, a few very
subtle warm embers near lower right. Keep the entire left two-thirds almost
uniformly black charcoal with ample clean negative space for white typography.
Keep the right central area also dark and quiet for real app screenshots to be
composited later. Minimal, sophisticated, high contrast, subtle depth, no dramatic
flames, no busy geometric pattern. Opaque background.
